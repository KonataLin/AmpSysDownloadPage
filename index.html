安装

解压整个 release 目录，不要只复制单个可执行文件。正常情况下 PluginRoot 和 EngineRoot 指向同一目录。

Windows

powershell -ExecutionPolicy Bypass -File <plugin-root>\install_windows.ps1 `
  -PluginRoot <plugin-root> `
  -EngineRoot <plugin-root>
py -3 <plugin-root>\tools\check_environment.py

Linux / Virtuoso

bash /opt/AmpSysCadencePlugin/install_linux.sh \
  /opt/AmpSysCadencePlugin \
  /opt/AmpSysCadencePlugin \
  ~/.cdsinit
source ~/.bashrc
py -3 /opt/AmpSysCadencePlugin/tools/check_environment.py

使用流程

页面只保留下载前最关键的路径，完整细节在压缩包内的 Usage.md。

01

Windows 建 LUT cache

用 HSPICE 建好完整 cache 目录，包含 pkl 和对应数据目录。

02

复制到 Linux

复制整个 cache 目录到 Virtuoso 可访问的位置，不沿用 Windows 盘符路径。

03

从 Virtuoso 提取

打开真正包含 MOS 的 schematic，点击 AmpSys 菜单提取当前原理图。

04

运行并回填

填写器件 Id 和 specs，Run Optimization 后确认回填到 Cadence。

支持范围

  • 支持 Windows x86_64，以及 Linux x86_64 + glibc >= 2.17。
  • 不支持 ARM、macOS、Alpine/musl、glibc < 2.17 或 32-bit 系统。
