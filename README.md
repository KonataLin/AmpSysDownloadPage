# AmpSys Download Page

Static GitHub Pages download page for AmpSys Cadence Plugin.

## Release ZIP

The page downloads:

https://github.com/KonataLin/AmpSysDownloadPage/releases/download/v1.0.0/AmpSysCadencePlugin_release.zip

To update the downloadable package, replace the `AmpSysCadencePlugin_release.zip` asset on the `v1.0.0` GitHub Release.
