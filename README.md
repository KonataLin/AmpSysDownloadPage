# AmpSys Download Page

Static GitHub Pages download page for AmpSys Cadence Plugin.

## Release ZIP

The page downloads:

https://github.com/KonataLin/AmpSysDownloadPage/releases/download/v0.1.0-alpha.9/AmpSysCadencePlugin_release_alpha9_clean_cross_pdk_20260727.zip

To update the downloadable package, upload or replace the release asset on the matching GitHub Release tag and update `app.js` / `index.html`.
